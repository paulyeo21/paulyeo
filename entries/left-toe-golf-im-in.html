Left Toe Golf: “I'm in”

Left Toe Golf started as a watcher — it polled courses every minute and texted you when a tee time opened up. That's gone. The new core is “I'm in”: a shareable game link that gets a group committed to a round.

Create a game — course, date, time window, group size — and drop the link into any group chat. The page shows live availability for that window, who's in, and a spots-left counter. Tapping “I'm in” takes a name and phone number, nothing else. No accounts, no app. Spots fill first-come-first-served; extras land on a waitlist and get promoted automatically (with a text) when someone drops.

When the group hits quorum, the organizer gets an SMS with a deep link to the course's booking page. Once they confirm the booked time, everyone who's in gets a confirmation text. It also works in reverse — if you already booked a tee time, create the game with the reserved slot and use the link to fill the remaining seats. And if the booked time moves after confirmation, re-locking the game texts the group the change.

The tradeoff behind the pivot: constant machine-paced polling is exactly what booking sites block, and it doesn't scale. Tee times are now fetched on demand — when someone runs a query or opens a game link — behind a short-TTL cache, so a burst of link opens is one upstream fetch. The notification flips from “a slot opened” to “someone started a game,” which is the text you actually wanted anyway.

Start a game: lefttoegolf.com/g/new
